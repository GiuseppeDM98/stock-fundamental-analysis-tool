## AI Portfolio Advisor (`/advisor`)

- Conversational chat with full context of the user's portfolio + saved analyses; the first step of the pipeline (Discover) and the only place for hold/add/exit reasoning (the valuation is position-blind: valutazione.md § 2.6). It never emits a valuation. Builders in `lib/ai/advisor-prompts.ts`, endpoint `/api/ai/advisor`. Request: `{ messages, language, mode: "portfolio" | "discovery" = "portfolio" }`.
- **Dual mode**: **Portfolio** (default) has portfolio/analyses context; **Discovery** (`buildDiscoverySystemPrompt`) has none — surfaces 3–5 candidates (thesis, ROIC, valuation, risk). Toggle persisted in `sfa:advisor-mode`; the route skips the DB fetch in discovery (AGENTS.md › Mode-conditional DB fetch in API routes).
- **Context injection** (Portfolio): it receives the deterministic per-ticker summary (latest analysis + consensus + verdict + signal + watchlist target), one line per ticker under `TICKER SUMMARIES (deterministic, from saved analyses)` — `buildTickerSummary` + `formatTickerSummaryForPrompt`, valutazione.md § 2.10 — never the saved analyses themselves. The route reads in parallel the open positions, the finished analyses through `ANALYSIS_SUMMARY_SELECT` (no report, no critique; valutazione.md § 2.9), and one batch query each for the watchlist items and the earnings estimates; a held ticker with no analysis gets a `no valuation` line. The prompt tells the model the figures are computed in code and to quote them as given: no valuation is born here (valutazione.md § 2.6).
- **Authoritative live prices** (Portfolio): the route `getQuote`s the open positions and every ticker whose analysis carries values (a verdict needs a price; until 2026-11-28 only the held ones), `Promise.allSettled`, best-effort — a 429/delisting on one is dropped, not fatal, and its line has no verdict —, keys each quote by the ticker asked, and passes `livePrices: LivePrice[]` (`ticker`/`price`/`currency`/`changePercent`) rendered as a `LIVE PRICES (authoritative …)` block via `formatLivePrice()`. Ground truth for a listed ticker's price — the model must not override it with a stale web quote/memory. Discovery has no positions → no block.
- **Grounding rules** (both modes): module-level `GROUNDING_RULES_BLOCK` — LIVE PRICES is the sole current-price source; the summaries' fair values are point-in-time, only their price is current; **web-verify any cited cause/event/news/guidance with a date, else "unconfirmed"** (fixes invented narratives); separate verified facts from inference; read the live price + search news before hold/add/exit advice. Why it exists: valutazione.md § 6.1.
- **`[[TICKER]]` chips**: Claude wraps tickers → `preprocessMarkdown()` → `/analyze?ticker=XXX` chip (full `window.location` nav — Router-Cache gotcha #15; the chip markup: AGENTS.md › Chips inside ReactMarkdown).
- **Sessions**: `AdvisorSession` + `AdvisorMessage`; full sync per response via `DELETE + createMany` in a `$transaction` (`POST /api/advisor/sessions/[id]/messages`, full replace). Sidebar ordered by `updatedAt desc`, auto-loads most recent; below `lg` it is a portaled drawer (AGENTS.md › Drawers).
- **Streaming**: `content_block_delta`, `max_tokens: 16000` (thinking + web search count toward budget). Tracks `stop_reason`; appends a visible EN/IT note on `max_tokens` or `refusal`.
- **Model**: the user's stored default, Sonnet 5.5 `high` as the route fallback, per-run override through `<AiSettingsControl>` (valutazione.md § 6.2).
- **Delisted guard**: both builders require web-verifying a ticker is currently listed before recommending it (prompt-level; a deterministic `/api/quote` check is a future enhancement).
